# dew-fixtures

Recorded test fixtures for [Dew](https://github.com/AshishKumar4/dew). Each file is a release asset named by its SHA-256, pinned beside the fixture it stands for in Dew's `tests/fixtures/`, and licensed as the reference it records, as its pin names. Only files under Apache-2.0, MIT or the owner's own code are kept here.
